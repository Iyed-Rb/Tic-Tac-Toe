# Tic-Tac-Toe (C# WinForms)

This is a simple Tic-Tac-Toe (X/O) game built using **C# and Windows Forms**.  
The game supports two modes: **Player vs. Player** and **Player vs. Computer**, with a clean graphical interface.

---

## 🎮 Features

- Two Game Modes:
  - 👤 vs. 👤 Player vs. Player
  - 👤 vs. 💻 Player vs. Computer
- Win detection (rows, columns, diagonals)
- Game reset button
- User-friendly button-based interface

---

## 🛠️ Technologies

- **Language:** C#
- **Framework:** .NET Framework / WinForms
- **IDE:** Visual Studio

---

## 🚀 How to Run

1. Open `TicTacToeProject.sln` in **Visual Studio**
2. Build the solution
3. Run the application
4. Choose your game mode and enjoy!
